# Student Submissions Guide 🎓

Welcome to the student submission area!

## 📌 Instructions

1. **Create your own folder** inside this `students/` directory.
   - **Naming Convention:** `firstname-rollno`
   - Example: `rahul-23cs104`

2. **Work ONLY inside your folder.**
   - Do NOT modify the `core/` folder.
   - Do NOT modify `mini-projects/` in the root (copy them to your folder if you want to work on them).

3. **Folder Structure Example:**
   ```
   students/
   └── rahul-23cs104/
       ├── assignments/
       │   ├── week-01/
       │   └── week-02/
       ├── practice/
       └── mini-projects/
       
   ```

4. **Commit Messages:**
   - Please use clear commit messages.
   - Example: `"Completed closures assignment - Rahul"`

5. **Branching Rule (Recommended):**
   - Work on a branch named `student/your-name`.
   - ❌ **Do NOT push directly to `main`**.

Happy Coding! 🚀
